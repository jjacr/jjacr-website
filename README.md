# JJACR Website

Sample GitHub Pages website for JJ Air Conditioning & Renewables Ltd.

## Files

- `index.html` — main webpage
- `style.css` — website styling

## GitHub Pages

1. Create a new GitHub repository, for example `jjacr-website`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the website address.

## Before launch

Replace the sample:
- Phone number
- Email address
- Service area
- About text
- AC manufacturers
- Installation photo
- Company registration details
- F Gas / REFCOM details and other accreditations
- Enquiry form with a proper form service

The current quote form uses `mailto:` only as a temporary demonstration.
